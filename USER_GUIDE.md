# User Guide — MATLAB Fastener Analysis Tool

The user guide now lives in the app: **Help → User Guide** opens
`matlab/userguide/index.html`, covering every GUI page plus what the tool
does not do and where the numbers come from. The files are plain HTML,
edited by hand, under `matlab/userguide/`.

Running analyses from the MATLAB Command Window instead of the GUI is
covered on its own page: `matlab/userguide/commandwindow.html`.
