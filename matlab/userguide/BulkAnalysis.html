Bulk Analysis

Run every mapped element and review the results in three tabs: Joint Summary, By Load Case and By Element.

Fields

FieldWhat it sets
Failures OnlyShow only failing rows. On by default. Display only; counts and export include everything.
Show SupplementalAlso show the TM-106943 columns (bearing, tear-out, thread checks). Display only.
Cap MS > 5Show margins above 5 as >+5. Display only.

By Load Case

FieldWhat it sets
Load CaseThe load case the tab shows.

What you'll see

  • Failures Only is ticked on first view, so a passing run shows an empty table. Untick it to see every row.
  • Run Bulk Analysis checks first that joints, mapping and forces line up, and offers to go to the page that needs fixing.
  • The Interaction column is a ratio R (fails above 1), never a margin.
  • Show in Single Joint Analysis re-runs the selected element on the Results page from the current inputs.
  • Export… always writes the complete result set, whatever the filters show.
  • The joint filter in the toolbar narrows every tab to one joint (display only).
