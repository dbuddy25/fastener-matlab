Defined Joints

Review the joints saved in this case with Save to Defined Joints. The bulk run analyses each mapped element against one of these.

Fields

This page has no named input fields. Select a joint in the list; edit its name in the box above Load, Rename and Delete.

What you'll see

  • The list is saved in the case file. Materials & Hardware is the other library, and it is shared by every case.
  • The summary shows only the identifying fields. Press Load to see the whole joint on Joint Config. It asks first only if Joint Config holds unsaved work.
  • Rename moves every element mapped to the old name with it. Names collide ignoring case.
  • Delete states how many mapped elements will be left without a joint before asking.
