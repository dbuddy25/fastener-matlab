Element Forces

Import the FE element forces, one load case per sheet. The bulk run resolves each element's forces into bolt tension and shear along the joint's bolt axis.

Fields

This page has no named input fields. Set each load case's Scale and Reversible in the summary table.

What you'll see

  • Units are fixed: forces in lbf, moments in in-lbf. There is no unit switch.
  • Scale and Reversible are set here, per load case (see below). They are never read from the file, and Merge keeps them.
  • A load case with 0 elements shows amber.
  • The cross-check panel compares the mapping with the imported forces. A file that covers none of the mapped elements shows red.
  • Re-importing asks: Merge (update matching element and load case) or Replace.

How forces become bolt loads

Each element is treated as one bolt: its forces are projected onto the joint's Bolt axis (Joint Config → Analysis assumptions). There is no load distribution across a bolt pattern.

Bolt loadFrom the element (bolt axis Z shown)
Tension PtLThe force along the bolt axis, FZ. Positive is tension.
Shear PsL√(FX² + FY²), the two forces across the bolt
Bending MbL√(MX² + MY²), the two moments across the bolt. Feeds the interaction check (5020B Eq. 20/22).
—MZ, the moment about the bolt axis (torsion), is ignored.
Load case settingEffect
ScaleMultiplies all six components before they are resolved. Default 1.
Reversible offCompression is ignored: PtL = max(axial, 0).
Reversible onThe load can reverse, so compression counts as tension: PtL = |axial|.

Import Workbook… file format

An .xlsx workbook, one sheet per load case. The sheet name is the load case name.

ColumnRequiredMeaning
element_idYesFE element ID.
FX, FY, FZYesElement forces, lbf.
MX, MY, MZYesElement moments, in-lbf.
  • Header names are matched ignoring case, and the header row is found automatically.
  • A sheet missing any of the seven columns is skipped and reported, e.g. a README sheet.
  • A row with values but a blank element_id is skipped and reported. A blank force cell reads as 0.
  • Text in a force cell stops the import. Nothing is changed.
  • Export Template… writes a workbook in this layout, with a README sheet and two example load cases.
