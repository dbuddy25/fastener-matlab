REFERENCE

Materials & Hardware

Browse the materials and hardware the tool knows, and the cited source behind every value. Add custom entries.

Fields

FieldWhat it sets
SourceFilter by origin: Baseline (ships with the tool), Drop-in (JSON files in your fastener_library folder) or Custom (added here).

What you'll see

  • Six tabs: Materials, Bolts, Bolt Specs, Nuts, Washers, Inserts.
  • The Source column cites the standard and table behind each entry. Check it first when a number surprises you.
  • Baseline and drop-in entries are read-only here; edit their files in your library folder instead.
  • Duplicate as Custom opens a pre-filled form. Change the values and give their source; a citation is required.
  • Every material can be used for a flange/clamped member. Tick Bolt material and/or Washer material on the Materials form to also offer it in those pickers on Joint Config.
  • This library is shared by every case and is not saved in the case file. Save Library writes your custom entries, and is enabled once there are any.
  • Custom entries are saved to fastener_library.json in your MATLAB user folder (usually Documents\MATLAB). Drop-in files go in fastener_library\<category>\*.json beside it, and factor presets live there too.
  • Open Library Folder shows the whole library in File Explorer, one JSON file per entry under fastener_library\<category>\: a copy of every shipped entry, plus any you add. Everything in that folder is yours to edit; changes load when you click Reload Library (or restart the tool). A reload marks any result on screen stale. A new material you add there is checked (a negative strength, yield above ultimate or a CTE not in 1/°C is skipped, and this page says why); an edited shipped entry is used as you wrote it.
  • Updates never overwrite your edits. A new version of the tool refreshes only the copies you have not changed, so corrections still reach you. Delete a shipped copy and it comes back on the next start.
  • Choose Library Folder… moves the library, your custom entries and factor presets to a folder you choose, such as a synced OneDrive folder shared by your machines. Files are copied only where none exists yet: nothing is overwritten, and the old folder is left as it was. Save Library first.
Edit the copies in your library folder, never the files inside the installed toolbox. Those are the originals your copies are refreshed from, and an update replaces them, so an edit there is lost.
