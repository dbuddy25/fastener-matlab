SETUP

Project

Record who ran the analysis and what it is for. Nothing here reaches a margin. It is saved with the case and heads every PDF report and Excel export.

Fields

Project

FieldWhat it sets
AnalystWho ran the analysis.
ProgramThe program the joint belongs to.
AssemblyThe assembly the joint is in.
Part NumberThe part or drawing number.
EnvironmentThe loading environment, e.g. Quasistatic, Random Vibration, Temperature Survival.
NotesFree text. Saved with the case.

What you'll see

  • There is no date field. The report stamps the run time itself.
  • Reports and exports read these fields when the file is written, so an edit here shows up on the next export without re-running.
  • A blank field prints as — on the report, so an unfilled field is visibly unfilled.
  • Opening a case that carries extra project fields keeps them; editing here never drops them.
