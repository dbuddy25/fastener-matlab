SINGLE JOINT

Single Joint Results

Every check the engine computes, one row each: the margin, its status, and the equation that produced it. Select a row to see the inputs behind it.

Fields

FieldWhat it sets
Cap MS > 5Show margins above 5 as >+5. Display only; untick to see the number.

Reading a row

StatusMeans
PassMS ≥ 0 (or R ≤ 1 for Interaction).
FAILMS < 0 (or R > 1). The whole row is painted.
Not evaluatedA required input is missing, so the value shows —. Not a pass. The row's Method names what is missing.
Assured / Not assuredSeparation-before-rupture only. A branch choice, not a verdict.
  • The verdict line never reads "All … pass" while any row is Not evaluated. It reads "N displayed checks pass, M NOT EVALUATED".
  • Only one threaded-member type applies to a joint. The rows for the other types read Not evaluated; that is expected.
  • Cap MS > 5 shows large margins as >+5. Untick it to see the number.
  • Method names the equation that ran and the basis of the allowable (rated, computed, or derived).

Two rows that are not margins

Interaction reports a ratio R, and passes when R ≤ 1, the opposite direction from MS ≥ 0. It never sets the worst margin, but a failing R still fails the verdict. It reads R = 0.83 (<= 1).

Separation-before-rupture decides which tension equation runs. Not assured is the conservative branch, not a failure. It leads the Analysis decisions panel below the table.

Below the table

  • Analysis decisions: which Fig. 8 branch ran and which allowable governed.
  • Warnings: never margins. For example, preload close to yield, or friction above the 5020B cap without test substantiation.
  • Scope note: the table is not a complete 5020B assessment. Yield and separation under combined loading are not implemented. See What the tool does not do.

Saving the result

  • Export Table... writes the rows to a workbook, with the project details on its About sheet.
  • Save PDF Report... writes a calc report stamped with the version, run time and project details.

Both are enabled only while the result is fresh. After any edit, re-run first.
