SETUP

Temp Loads

Set the three service temperatures, in °C. They are global: one trio for the single joint and every joint in a bulk run.

Fields

Service Temperatures

FieldWhat it sets
NominalAssembly / reference temperature, °C.
HotMaximum service temperature, °C.
ColdMinimum service temperature, °C.

What you'll see

  • Cold ≤ Nominal ≤ Hot is enforced as you type. An entry that breaks the order is refused and the last valid value comes back.
  • The temperatures drive the thermal preload change from the CTE mismatch between bolt and clamped stack (TM-106943 Eq. 10).
