ABOUT THE TOOL

Command Window (MATLAB)

This page requires MATLAB and the source install. It does not apply to the packaged .exe, which only runs the GUI.

Setup

Set the MATLAB Current Folder to the matlab/ subfolder, then sanity-check the install:

cd matlab
fastenerTool          % prints the version banner
runTests               % should be all green

Single joint

Build a joint from the built-in library, or load a saved case (see below). This example pulls a bolt and two materials, builds a two-layer flange stack, and analyzes it:

lib = data.Library.loadInstalled();
b   = lib.bolt("NAS1351 3/8-24");
bm  = lib.material("A286");
fm  = lib.material("Al 7075-T7351");

j = model.Joint(Name="Demo", Bolt=b, BoltMaterial=bm, ...
      FlangeStack=[model.FlangeLayer(Material=fm, Thickness=0.375), ...
                   model.FlangeLayer(Material=fm, Thickness=0.375)], ...
      ThreadedMember=model.ThreadedMember(Type=model.ThreadedMemberType.Nut), ...
      PreloadSpec=model.PreloadSpec(NominalTorque=470, TorqueTolerance=0.0426, ...
                                     NutFactor=0.15, Uncertainty=0.25), ...
      BoltCount=4, FrictionCoefficient=0.1, LoadingPlaneFactor=0.5, ...
      MinTemperature=6.1, MaxTemperature=33.9);

lc = model.LoadCase(Name="Quasistatic", BoltTensileLimitLoad=5590, BoltShearLimitLoad=1560);
f  = data.factorPreset("NASA-STD-5020B");

r = engine.analyze(j, lc, f);
r.asTable
r.WorstMargin
r.GoverningCheck

engine.summary(j, lc, f) prints every input, including the computed min/max preload, so you can double-check what went in before trusting the margins.

Reading the Result

FieldMeaning
r.asTable()One row per check: Name, MS, Status, Method (the equation citation)
MS ≥ 0Pass
MS < 0Fail
MS = NaNNotEvaluated — the check did not run (missing geometry, not applicable, or deferred). Not a pass, not a fail.
r.WorstMargin / r.GoverningCheckThe smallest evaluated margin and which check produced it
Interaction rowReports a ratio R, not a margin, in Margins(k).R — passes at R ≤ 1, the opposite direction from every other row, and is excluded from WorstMargin/GoverningCheck

PDF report

Requires the MATLAB Report Generator toolbox:

report.singleJointReport(j, lc, f, "report.pdf")

Builds a title page, an Inputs table, Preload and Design Loads tables, the full margins table (governing check bolded, Fail rows shaded), the separation-before-rupture narrative, and a Governing Equations table. Pass a Project= struct (fields analyst, program, assembly, partNumber, environment, notes) to stamp the report's Project section.

Export the margins table

Without a PDF, write just the margins table to Excel or CSV:

report.exportResults(r.asTable(), "margins.xlsx")

Save / load a case

Save a Joint (and, usually, a LoadCase and Factors) to one JSON file so you can reopen it later without retyping anything:

data.saveCase(struct(Joint=j, LoadCase=lc, Factors=f, Name="Demo"), "demo_case.json");

% ... later, in a new session ...
c = data.loadCase("demo_case.json");
r = engine.analyze(c.Joint, c.LoadCase, c.Factors);

The round trip is lossless — re-analyzing a loaded case reproduces the exact same margins as the original, including unconfigured (NaN) fields.

Factor presets

Pull a named safety/fitting-factor preset instead of typing model.Factors(...) every time:

f = data.factorPreset("NASA-STD-5020B");   % the built-in standard set
data.factorPresetNames()                   % every preset name available, built-in + yours

Save your own program-specific set for reuse — built-in names are protected and cannot be overwritten:

data.saveFactorPreset("My Program Factors", model.Factors(FSU=1.5, FFU=1.2));
f = data.factorPreset("My Program Factors");   % pulls it back, any session

Bulk

Fill three plain CSVs (or one multi-sheet workbook) and get a margins table out with one call.

TemplateWhat it holds
matlab/templates/joint_library_template.csvOne row per joint definition
matlab/templates/elements_template.csvOne row per FEM element × load case
matlab/templates/settings_template.csvGlobal temperatures + the eight safety/fitting factors
T = engine.runBulk("joints.csv", "elements.csv", "settings.csv", "margins.xlsx");

Prefer one workbook? data.makeTemplate("analysis_template.xlsx") writes a five-sheet fill-in workbook (Joints/Elements/Settings plus Lists and Fields for Excel dropdowns and tooltips); fill it in, then run it in one call:

T = engine.runWorkbook("analysis_template.xlsx", "margins.xlsx");

Either call writes a Results sheet (one row per element, same MS/NaN/Interaction rules as above) and a Summary sheet with Pass/Fail/Error counts. See matlab/examples/run_bulk_example.m for a runnable end-to-end example that copies the bundled templates and writes bulk_results.xlsx.
