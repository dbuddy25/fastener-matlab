User Guide

Fastener Analysis Tool

Margins of safety for preloaded bolted joints to NASA-STD-5020B. Run one joint on the Single Joint pages, or many at once from FE element forces on the Bulk pages.

Every result names the equation behind it. A check missing an input reports — Not evaluated, never a guessed number.

The rail

SectionPageUse it to
SETUPProjectRecord who ran the analysis and what it is for. Never analysed; travels with the case.
FactorsSet the factors of safety and fitting factors. Start from the 5020B preset.
Temp LoadsSet assembly, hot and cold temperatures. Global: they apply to every joint in the case.
SINGLE JOINTBolt SizingGut-check bolt capability across sizes before defining the joint.
Joint ConfigDefine the bolt, flange stack, threaded member and loads, then analyze.
Single Joint ResultsRead every check, its margin and the equation that produced it.
BULK1 · Defined JointsReview the joints saved in this case.
2 · Element MappingTie FE element IDs to those joints.
3 · Element ForcesImport element forces, one load case per sheet.
4 · Bulk AnalysisRun every mapped element: one row each, with its worst margin and the check that governed it.
REFERENCEMaterials & HardwareBrowse the library and the source behind every allowable. Add custom entries.

Where to start

  1. Project: fill in the project details.
  2. Factors: check the factors your program levies.
  3. Temp Loads: set the three temperatures.
  4. Joint Config: define the joint, then press Analyze Single Joint.
  5. Single Joint Results: read the margins.
